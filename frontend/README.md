# Frontend

A Sprint 02 entrega o protótipo navegável do produto no Figma e os arquivos exportados em `docs/prototypes`.

Esta pasta registra a transição do protótipo para a implementação. O frontend previsto usa React, Vite e TypeScript; o protótipo fornece uma referência inicial de fluxo e conteúdo, mas a interface poderá mudar durante o desenvolvimento e os testes de usabilidade.
